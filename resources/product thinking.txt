7. Don't let AI make architectural decisions for you
This is one of the most important rules I would give you.
AI is extremely useful at:
“Implement this.”
AI is much more dangerous when you ask:
“What architecture should I use?”
because it will happily produce a technically impressive architecture that you don't need.
For GridOps, your initial architecture should be deliberately boring:
React + TypeScript
        ↓
REST API
        ↓
Node.js + Express
        ↓
Prisma
        ↓
PostgreSQL
One backend.
One database.
One frontend.
Modular codebase.
That's enough.
Then document:
Why did we choose a modular monolith?
Answer:
The MVP has a small engineering team and a single cohesive domain. A modular monolith minimizes operational complexity while preserving clear domain boundaries that can be extracted later if required.
Now you've demonstrated engineering judgment.
8. Start using ADRs

28. The story I want an interviewer to hear
After you build this properly, I want you to be able to say:
“I initially considered building a generic AI project-management system, but I realized I could build something much more domain-specific around utility operations. I started with grievance handling because the core problem wasn't creating records—it was maintaining visibility into ownership, forwarding, deadlines and pending cases.
I modeled the grievance as a state machine and maintained an immutable activity history so we could answer not just the current state but how the case got there.
For the MVP I deliberately chose a modular monolith with PostgreSQL rather than microservices because the domain didn't justify the operational complexity.
I used AI extensively for implementation, but I defined the domain model, workflow rules, API contracts and architecture myself.
After the MVP, the architecture allows us to add meter challenges, work orders and GIS as additional domains without rewriting the core system.”
That is a very different candidate story from “I built a React app.”
And that is exactly the direction I would push you toward.
